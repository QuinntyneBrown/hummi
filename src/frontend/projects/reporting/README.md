# @hummi/reporting

Angular feature library in the Hummi frontend workspace: reporting a track (L2-038). It exports
`ReportDialogHostComponent` (`hm-report-dialog-host`), which the shell renders for `ReportDialogs` in
`@hummi/api`: the Report “{title}” dialog with its reason, details, busy, success and failure states. It has
no routes. Reviewers resolve reports outside the product (ADR 0018).
