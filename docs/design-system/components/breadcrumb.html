Breadcrumb

Shows where a page sits in the hierarchy and links back up.

WCAG 2.2 AAStatus: stable

Overview

Use on pages two or more levels below a top-level destination. Skip it on top-level pages.

Anatomy

  1. LinkAncestor pages
  2. SeparatorDrawn by CSS, hidden from screen readers
  3. CurrentPlain text, aria-current="page"

Variants

  1. Browse
  2. Ambient
  3. Slow Orbit
Default
HTML
<nav aria-label="Breadcrumb"><ol class="breadcrumb"><li><a href="#code">Browse</a></li><li><a href="#code">Ambient</a></li><li aria-current="page">Slow Orbit</li></ol></nav>

Responsive behaviour

On narrow screens only the parent link and current page show; earlier levels collapse into “…”.

Accessibility

Role and pattern

<nav aria-label="Breadcrumb"> with an ordered list.

Keyboard

KeyAction
TabMoves through the links

Focus

Standard ring.

Labelling

Current item uses aria-current="page".

Contrast

Link

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

Use page titles exactly. Truncate with an ellipsis only past 24 characters.
