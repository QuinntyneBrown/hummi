Form layout

How fields, the error summary and the actions bar sit together on a page.

Overview

Stack fields in one column. Show an error summary at the top after a failed submit, with links to each field, and keep the primary action at the end.

Anatomy

  1. Error summaryAppears after submit with links
  2. FieldsOne column, 16px apart
  3. Actions barPrimary then secondary

Responsive behaviour

Single column at every width; the actions bar stacks and primary buttons go block under 640px.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Accessibility

Role and pattern

Native form with novalidate and custom messages; the summary is role="alert".

Keyboard

KeyAction
EnterSubmits from any single-line field
TabMoves through fields in reading order

Focus

After a failed submit focus moves to the summary; each link jumps to its field.

Labelling

Summary heading counts the problems.

Contrast

Summary text

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

Validate on blur, re-validate on input once a field has been touched. Never clear what someone typed.
