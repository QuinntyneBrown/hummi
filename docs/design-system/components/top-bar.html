Top bar

The sticky header: navigation menu on small screens, search, notifications and account.

WCAG 2.2 AAStatus: stable

Overview

Every signed-in page has one top bar. It holds global actions only; page-specific actions live in the page header.

Anatomy

  1. Menu buttonVisible under 1024px; toggles the sidebar
  2. SearchAlways available; grows to fill free space
  3. ActionsNotifications and account, at the end

Menu button

Both themes

Responsive behaviour

Under 1024px the menu button shows and the sidebar collapses behind it; the search field takes all free space. At 1024px and above the sidebar is permanent and the menu button hides.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Accessibility

Role and pattern

<header> landmark; the search form is role="search".

Keyboard

KeyAction
TabMenu, search, notifications, account
/Focuses search (shortcut)

Focus

Standard ring; the skip link is the first focusable element.

Labelling

Icon buttons carry aria-label; the bell announces its unread count.

Contrast

Text on bar

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

Search placeholder lists what can be found: “Search tracks, artists, playlists”.
