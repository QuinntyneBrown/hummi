Select

A native dropdown for choosing one option from a fixed list.

WCAG 2.2 AAStatus: stable

Overview

Use the native select by default: it is accessible and works with every keyboard and screen reader. Use radio-group when there are fewer than five options.

Anatomy

  1. LabelAbove the control
  2. ControlNative select with the system arrow
  3. Help or errorAs text field

Variants

Default
HTML
<label class="field"><span class="field__label">Sort by</span><select class="select"><option>Newest</option><option>Most played</option><option>Title</option></select></label>
Invalid
HTML
<label class="field"><span class="field__label">Licence</span><select class="select" aria-invalid="true"><option>Choose a licence</option><option>CC0</option></select><span class="field__error">Choose a licence</span></label>

Sizes

Small
HTML
<select class="select input--sm" aria-label="Sort small"><option>Newest</option></select>
Medium
HTML
<select class="select" aria-label="Sort medium"><option>Newest</option></select>

States

VariantDefaultHoverFocusDisabledInvalid
Select

Both themes

Responsive behaviour

Native pickers are used on touch devices; width follows the column.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Accessibility

Role and pattern

Native <select>.

Keyboard

KeyAction
↑ / ↓Changes the option
Space / Alt+↓Opens the list
Type a letterJumps to a matching option

Focus

Standard ring.

Labelling

Label above; first option can be a prompt like “Choose a licence”.

Contrast

Border

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

Sort options by what people most often pick, or alphabetically for long lists.
