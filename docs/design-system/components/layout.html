Layout primitives

Container, grid, stack and cluster: the building blocks every page template uses.

Overview

Pages are built from four primitives. Use container for width and margins, grid for columns, stack for vertical rhythm and cluster for rows that wrap.

Anatomy

  1. ContainerMax width with responsive margins
  2. Grid4, 8 or 12 columns with responsive gutters
  3. StackVertical flow with a gap
  4. ClusterHorizontal flow that wraps

Responsive behaviour

Columns are 4/8/12, gutters 16/24/32px and margins 16/32/48px at 0/768/1024px. See the Layout foundation for the live grid.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Role and pattern

Presentational wrappers; semantics come from their content.

Keyboard

KeyAction
n/aNot interactive

Focus

Reading order equals DOM order; never reorder visually in a way that changes meaning.

Labelling

Landmarks are applied on the elements inside.

Contrast

Inherits text and surface pairs from the colour foundation.

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

No text content.
