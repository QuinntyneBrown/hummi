Waveform

A visual summary of a track’s loudness with the played portion highlighted.

WCAG 2.2 AAStatus: stable
  • Overview
  • Anatomy
  • Variants
  • Sizes
  • States
  • Responsive behaviour
  • Theming
  • Accessibility
  • Content
  • Do and don’t
  • Tokens

Overview

Decorative and informative: it shows shape and position. Seeking uses the progress rail in the player; the waveform itself is a picture.

Anatomy

  1. Bars64 rounded bars
  2. Played portionAccent colour up to the current position

Sizes

Not applicable: Height is 3rem.

States

Responsive behaviour

Bars flex to the container width, never below 2px each.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Accessibility

Role and pattern

role="img" with a label giving progress.

Keyboard

KeyAction
n/aNot interactive

Focus

Not focusable.

Labelling

Contrast

Played bar vs canvas
Unplayed bar vs canvas

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.
