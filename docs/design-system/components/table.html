Table

Compares records across columns. Scrolls inside its own wrapper on small screens.

WCAG 2.2 AAStatus: stable

Overview

Use a table when people compare values across rows. For a list of media or a feed, use list or track row instead.

Anatomy

  1. CaptionVisually hidden name of the table
  2. Header cellsth scope="col"
  3. Row headerth scope="row" for the identifying cell
  4. Wrappertable-wrap scrolls horizontally

Responsive behaviour

The wrapper scrolls horizontally; the page never does. First column stays readable by being the row header.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Accessibility

Role and pattern

Native table with caption and header scopes. Sortable headers use aria-sort.

Keyboard

KeyAction
TabReaches controls inside cells

Focus

Interactive cells use the standard ring.

Labelling

Caption names the table; headers describe columns.

Contrast

Cell text
Header text

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

Column headers are nouns; numbers are right-aligned with tabular figures.
