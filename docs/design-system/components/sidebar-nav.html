Responsive behaviour

At 1024px and above it is a sticky 256px column. Below, it is hidden until the menu button opens it as a full-height panel over the page.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Accessibility

Role and pattern

<nav aria-label="Primary"> with a flat list of links.

Keyboard

KeyAction
TabMoves between links
EnterFollows the link
EscCloses the mobile panel

Focus

Standard ring; opening the mobile panel moves focus to its first link.

Labelling

Current page uses aria-current="page"; badge counts have a spoken meaning.

Contrast

Current link
Link

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

One-word labels: Home, Browse, Search, Library, Notifications.
