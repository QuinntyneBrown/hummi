Button group

Joins related buttons into one segmented control or toolbar.

WCAG 2.2 AAStatus: stable

Overview

Use a group when the buttons act on the same thing and one is usually chosen: sort order, view mode. For a single choice from many options, use radio-group or tabs instead.

Anatomy

  1. Group containerrole="group" with an accessible name
  2. SegmentA button; the selected one has aria-pressed="true"

Variants

Segmented
HTML
<div class="btn-group" role="group" aria-label="Sort tracks"><button class="btn" type="button" aria-pressed="true">Newest</button><button class="btn" type="button" aria-pressed="false">Most played</button></div>

States

VariantDefaultHoverFocusActiveDisabled
Segment

Both themes

Responsive behaviour

Groups with more than three segments scroll horizontally inside their container instead of wrapping; labels stay on one line.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Accessibility

Role and pattern

role="group" with aria-label; each segment is a toggle button using aria-pressed.

Keyboard

KeyAction
TabMoves between segments
Enter / SpaceSelects the segment

Focus

Each segment shows the standard focus ring; the ring sits above neighbours.

Labelling

The group label says what the choice controls (“Sort tracks”).

Contrast

Selected label

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

Use one or two words per segment. Keep labels parallel (all nouns or all adjectives).
