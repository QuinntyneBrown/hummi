Alert and banner

Inline messages and page-wide banners in four tones.

WCAG 2.2 AAStatus: stable

Overview

Use an inline alert for state that belongs to a section, a banner for state that applies to the whole page (offline, maintenance, verify email).

Anatomy

  1. IconTone cue
  2. TitleShort statement
  3. BodyWhat to do
  4. Actions (optional)A link or button

Responsive behaviour

Banners wrap their text and keep icon alignment; actions drop below the text under 640px.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Accessibility

Role and pattern

role="alert" only for new, important content; otherwise role="status" or none.

Keyboard

KeyAction
TabReaches any action or dismiss button

Focus

Never moves focus.

Labelling

Tone is stated in words as well as colour.

Contrast

Info
Success
Warning
Danger

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

State the fact, then what to do. “We couldn’t save your changes. Try again.”
