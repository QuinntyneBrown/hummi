Tooltip

A short label that appears on hover and focus.

WCAG 2.2 AAStatus: stable

Overview

Use a tooltip to name an icon-only control or give a one-line hint. Never put interactive content or essential information in one.

Anatomy

  1. TriggerAny focusable element
  2. BubbleInverse surface, role="tooltip"

Variants

On an icon button
HTML
<button class="btn btn--ghost btn--icon has-tooltip" type="button" aria-label="Queue"><svg class="icon" aria-hidden="true" viewBox="0 0 24 24"><path d="M4 6h12M4 11h12M4 16h7M17 14v6l5-3z"/></svg><span class="tooltip" role="tooltip">Queue</span></button>

Sizes

Not applicable: One size.

States

VariantDefaultHoverFocus
Trigger

Both themes

Responsive behaviour

Hidden on touch-only devices; the control’s aria-label is the real name.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Accessibility

Role and pattern

role="tooltip", referenced by aria-describedby on the trigger.

Keyboard

KeyAction
FocusShows the tooltip
EscHides it

Focus

Shows on keyboard focus as well as hover.

Labelling

Repeats or adds to the accessible name; never replaces it.

Contrast

Text

Motion

Fades in after 300ms, out instantly.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

One to four words, no full stop.
