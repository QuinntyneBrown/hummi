Share sheet

The Share dialog for a track or playlist: link or embed code, Copy, an optional start time and quick send targets.

WCAG 2.2 AAStatus: stable

Overview

A modal sheet centred over the page (L2-025). Link shows the share link with Copy; Embed shows a preview card and the iframe code with its own Copy. Copy reads “Copied” for a moment and a status line announces it.

Anatomy

  1. HeadCover, “Share {name}” and the free-to-play line
  2. TabsLink and Embed segmented tabs
  3. Link boxThe link without its scheme and Copy
  4. Start atOnly for the current track once it has played
  5. Send it straight toWhatsApp, Email and Messages

Accessibility

Role and pattern

role="dialog" with aria-modal, named by its heading; the tabs are a tablist.

Keyboard

KeyAction
EscapeClose
TabStays inside the sheet
← / →Switch Link and Embed

Focus

The panel takes focus on open and Tab is trapped inside it.

Labelling

Copy announces “Link copied.” in a status region.

Contrast

Link
Copy

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

Name what is shared in the heading. Say it is free to play with no account.
