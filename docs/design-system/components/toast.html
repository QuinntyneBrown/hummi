Toast

A transient message about something that just happened.

WCAG 2.2 AAStatus: stable

  • Variants

Overview

Use for confirmation of a completed action, with Undo when reversible. Errors persist until dismissed. For page-wide state use a banner.

Anatomy

  1. IconTone cue beyond colour
  2. Title and textWhat happened and what is next
  3. ActionUndo, View or Retry
  4. DismissLabelled close button

VariantDefaultHoverFocus
Dismiss

Stacking and dismissal: see toast · stacked.

Both themes

Responsive behaviour

The region spans the width with a 16px margin on phones and sits bottom-right from 640px. At most three toasts show.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Accessibility

Role and pattern

Region is role="status" aria-live="polite" and exists before toasts arrive; errors use role="alert".

Keyboard

KeyAction
TabReaches the action and dismiss button
EscDismisses the focused toast

Focus

Toasts never steal focus.

Labelling

Dismiss is labelled; actions name the verb.

Contrast

Text

Motion

Slides in and out in --duration-base. Auto-dismiss (8s) pauses on hover and focus; errors never auto-dismiss.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

Title says what happened in the past tense; text says what is next. No exclamation marks.
