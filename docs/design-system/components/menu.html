Menu

A short list of actions opened from a button, such as a track’s More menu.

WCAG 2.2 AAStatus: stable

  • Anatomy
  • Variants

Overview

Use a menu for three or more secondary actions on one object. Put the one or two common actions directly on the row instead.

Anatomy

  1. TriggerButton with aria-haspopup="menu" and aria-expanded
  2. PanelRaised surface with --shadow-3
  3. ItemAction row; danger items sit last after a divider
  4. DividerSeparates destructive actions

Variants

Menus are shown open here. In the product the panel is anchored below the trigger and closes on selection.

Default
HTML
<div class="menu" role="menu" aria-label="Track actions"><button class="menu__item" role="menuitem" type="button">Add to queue</button><button class="menu__item" role="menuitem" type="button">Add to playlist</button><div class="menu__divider" role="separator"></div><button class="menu__item menu__item--danger" role="menuitem" type="button">Report track</button></div>

Sizes

Not applicable: Menus take the width of their widest item, with a 12rem minimum.

States

VariantDefaultHoverFocusDisabled
Item

Both themes

Responsive behaviour

Under 640px a menu with more than five items becomes a bottom sheet (see Dialog) so items are 44px tall.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Accessibility

Role and pattern

WAI-ARIA Menu Button pattern: role="menu" and role="menuitem".

Keyboard

KeyAction
Enter / Space / ↓Opens the menu, focuses the first item
↑ / ↓Moves between items
Home / EndFirst or last item
EscCloses and returns focus to the trigger
Type a letterJumps to the matching item

Focus

Focus moves into the menu on open and returns to the trigger on close.

Labelling

The menu has an aria-label naming the object (“Track actions”).

Contrast

Item text
Danger item

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

Verb first, sentence case. No more than seven items; group with dividers.
