Form field

The wrapper every input uses: label, control, help, error and counter in a fixed order.

WCAG 2.2 AAStatus: stable

Overview

Wrap every input in a form field so spacing and error placement are the same everywhere.

Anatomy

  1. Labelfield__label
  2. ControlInput, textarea or select
  3. Helpfield__help
  4. Errorfield__error, replaces help
  5. Counterfield__counter for hard limits

Variants

Sizes

Not applicable: The field takes the width of its container.

States

VariantDefault
Field

Both themes

Responsive behaviour

Gap between parts is 4px; gap between fields is 16px; two-column forms use .grid and collapse under 768px.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Up to 60 characters
Up to 60 characters

Accessibility

Role and pattern

Label is a <label for>; help and error are referenced by aria-describedby.

Keyboard

KeyAction
TabMoves between fields

Focus

On the control, never on the wrapper.

Labelling

Required fields say “required” in the label text; an asterisk alone is not enough.

Contrast

Help text
Error text

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

Labels are short nouns; help is one sentence; errors say how to fix.
