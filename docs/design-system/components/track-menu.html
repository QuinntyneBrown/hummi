Track menu

The More actions menu of one track: queue it, save it, share it, or go to its artist or genre.

WCAG 2.2 AAStatus: stable
  • Overview
  • Anatomy
  • Variants
  • Sizes

Overview

Opens from a card, a track row, a search song, the player bar or Now playing, anchored to the button that opened it and kept inside the viewport. A transparent scrim closes it on outside clicks.

Anatomy

  1. HeadCover, title and “{artist} · {duration}”
  2. Queue itemsPlay next, Add to queue
  3. Library and sharingSave to library (Remove from library when saved), Share
  4. Go toMore from {artist}, Go to {genre}

Responsive behaviour

Opens below its anchor, right-aligned; flips above when there is no room; stays 8px inside every viewport edge.

Theming

Component tokens alias semantic tokens only; re-theme by overriding the semantic tokens, never the component CSS.

Accessibility

Role and pattern

role="menu" “Track actions” with menuitem buttons.

Keyboard

KeyAction
↑ / ↓Move between items
Enter / SpaceChoose
Escape / TabClose; focus returns to the opener

Focus

The first item takes focus on open.

Labelling

Items are named by their text.

Contrast

Item
Meta

Motion

No motion beyond colour transitions, which collapse to zero under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px on touch-primary controls.

Content

Choosing Play next or Add to queue confirms with a toast pill (L2-041).
