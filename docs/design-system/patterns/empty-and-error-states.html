Overview

Empty and error states keep the page chrome, explain what is going on and offer one next step.

When to use what

StateUse whenComponent
First runNothing exists yetEmpty state
No resultsFilters or search matched nothing; keep filters visibleEmpty state
PermissionThe person cannot see thisEmpty state with sign-in action
Load errorA request failedEmpty state, error tone, with Try again
Page errorRoute-level 404, 403, 500, offlineError page
