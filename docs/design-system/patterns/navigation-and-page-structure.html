Navigation and page structure

Shell, page header, breadcrumbs and back behaviour.

WCAG 2.2 AAStatus: stable

  • Structure

  • Responsive behaviour

Overview

Every page sits in the same shell: sidebar, top bar, main and player bar.

When to use what

  • Top-level destinations live in the sidebar; there are five.
  • Use tabs for peer views of the same content; sub-pages when each has its own URL and heavy content.
  • Breadcrumbs appear two levels down.

Structure

  1. Browse
  2. Ambient

Ambient

1,204 tracks

States

Current location is marked with aria-current. The page header keeps its title in every state, including loading and error.

Responsive behaviour

Sidebar collapses under 1024px; the page header wraps actions below the title.

Accessibility

  • Landmarks: header, nav, main, footer; skip link first.
  • Back uses the browser history; no custom back buttons.

Content

Page titles are nouns; actions are verbs.
