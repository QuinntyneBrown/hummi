Pattern

Data tables and lists

Density, selection, bulk actions and responsive strategy.

WCAG 2.2 AAStatus: stable
  • Overview
  • When to use what
  • Structure
  • States
  • Responsive behaviour
  • Accessibility

Overview

Tables compare; lists browse. Hummi mostly browses, so lists and track rows dominate.

When to use what

  • Track collections: track rows.
  • Two-line records: list.
  • Comparing attributes: table (licences, settings).

States

Selected rows show a bulk action bar above the list (see Playlist · selected). Loading uses skeleton rows; empty states replace the list; no-results keeps filters visible.

Responsive behaviour

Tables scroll inside table-wrap; track rows truncate and hide secondary columns on phones.

Accessibility

  • Tables have a caption and header scopes.
  • Row actions are reachable by keyboard.

Content

Column headers are nouns; numbers align right.
