Foundation

Responsive

Design for 360px first, then add columns and navigation at 768px and 1024px.

WCAG 2.2 AAStatus: stable
  • Overview
  • Rules
  • Per-component behaviour
  • Testing matrix

Overview

Every screen is checked at 360, 768 and 1280px in both themes with no horizontal page scroll. Hover-only affordances are always visible under (hover: none).

Rules

  • Base styles are for 360px; use min-width media queries.
  • Tables and pill rows scroll inside their wrapper.
  • Dialogs become bottom sheets under 640px.
  • The sidebar hides under 1024px behind the menu button.
  • Body text stays 16px; inputs are never smaller than 16px on touch.
