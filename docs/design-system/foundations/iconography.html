Foundation

Iconography

Line icons on a 24-unit grid with a 2px stroke, drawn in currentColor.

WCAG 2.2 AAStatus: stable
  • Overview
  • Sizes
  • Icon set
  • Labelling
  • Usage

Overview

Icons are inline SVG, viewBox="0 0 24 24", 2px stroke, round caps and joins, no fill (the play glyph is the exception). They inherit currentColor so they follow text and theme.

Sizes

16px (sm), 20px (default), 24px (lg)

Labelling

  • Decorative icons next to text: aria-hidden="true".
  • Icon-only buttons: aria-label on the button naming the action and object.
  • Meaningful standalone icons: role="img" with a label, or hidden text.

Usage

One icon per control. Pair icons with text in navigation and primary buttons. The logo is a separate asset: see assets/ in this folder and the brand rules in docs/design-system/assets/README.md.
