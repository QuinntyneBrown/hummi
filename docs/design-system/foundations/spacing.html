Spacing

A 4px scale. Small steps inside components, larger steps between them.

Overview

Every gap, padding and margin is a multiple of 4px. Use ≤ --space-6 inside a component and ≥ --space-6 between components.

Inside and between

  • Inside: 4px between a label and its field, 8px between icon and text, 12–16px padding in rows, 24px in cards.
  • Between: 16px between fields, 24–40px between sections on a page, 64–96px for hero blocks.
  • Page gutters and margins come from layout tokens, not the scale directly.
