Foundation

Color

Coral, cream and plum ink: a warm brand palette with a cool info blue and calm status colours. Every pairing passes WCAG 2.2 AA in both themes.

WCAG 2.2 AAStatus: stable

Overview

Colour has three jobs: brand (coral), structure (cream and plum neutrals) and meaning (info, success, warning, danger). Components read semantic tokens only; primitives are never used directly. Dark is built from roles, not inverted: surfaces rise lighter than the canvas, coral becomes brighter, and text on coral flips to plum.

Usage

  • Use --color-accent for the one main action per view; --color-fg-accent for accent-coloured text.
  • The pure brand coral (--palette-coral-500) is for the logo, favicon and large surfaces; interactive coral in light is the deeper --palette-coral-600 so text and focus rings reach 4.5:1 on cream.
  • Never rely on colour alone: badges, errors and states always have text or an icon.
  • Add a brand theme as a [data-theme="name"] block overriding semantic tokens only.
