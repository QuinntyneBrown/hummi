Foundation

Layout

Mobile-first grid: 4, 8 and 12 columns with growing gutters and margins, a sticky sidebar from 1024px.

WCAG 2.2 AAStatus: stable

Overview

Layout is mobile first. Base styles target 360px; additions apply at 48rem (768px) and 64rem (1024px). The page never scrolls horizontally; tables and pill rows scroll inside themselves.

Container, sidebar and top bar

  • --layout-container-max caps content width; container--narrow (42rem) is for reading and forms.
  • The sidebar is --layout-sidebar-width; the top bar is --layout-topbar-height.
  • The player bar sits above content and pages add has-player to reserve its height.

Usage

Compose with stack, cluster, grid and container (see Layout primitives). Do not set widths in pixels; use tokens and fractions.
