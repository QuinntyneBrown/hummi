Foundation

Motion

Short, purposeful transitions that respect reduced-motion.

WCAG 2.2 AAStatus: stable
  • Overview
  • Durations
  • Easings
  • Usage
  • Reduced motion
  • Tokens

Overview

Motion confirms an action or shows where something came from; it never decorates. Under prefers-reduced-motion the duration tokens drop to zero, so components need no extra rules.

Durations

--duration-instant
--duration-fast
--duration-base
--duration-slow
--duration-deliberate

Easings

--ease-standard
--ease-enter
--ease-exit
--ease-spring

Usage

MotionDurationEasing
Hover, colour changefaststandard
Tooltip, menu revealbaseenter / exit
Dialog, sheetslowenter
Skeleton shimmer, indeterminate bardeliberatestandard

Reduced motion

With prefers-reduced-motion: reduce: durations are 0ms, shimmer and spinner become static, smooth scrolling is off. Nothing flashes more than three times a second.
