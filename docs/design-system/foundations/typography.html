Typography

DM Sans for everything and the system monospace for code. A nine-step scale, four weights and twelve ready-made roles.

WCAG 2.2 AAStatus: stable

Overview

Hummi sets in DM Sans (400, 500, 600, 700) with system sans-serif fallbacks. Body text is 16px; nothing is smaller than 12px. Headings use tighter line heights and balanced wrapping.

Usage

  • One h1 per page using --text-h1; headings never skip levels.
  • Line length stays under 65 characters (--layout-measure).
  • Numbers in tables and the player use tabular figures.
  • On phones the display and h1 steps shrink one step; body stays 16px so mobile browsers do not zoom inputs.

Accessibility

Text sizes are in rem so browser zoom and user font settings apply. Body line height is 1.5. Large text (24px, or 18.66px bold) needs 3:1 contrast; everything else 4.5:1.
