# User Journeys

Ordered by value to the user, highest first. Effort is in days and matches `docs/estimates/`.

| Name | Description | Effort (days) |
|---|---|---|
| Set up the workspace | Developer runs one command and gets a building, testable backend and Angular shell | 3 |
| Play a track without an account | Visitor presses play on any track and hears it through the player bar | 13 |
| Browse genres | Listener picks a genre from Browse, sorts its tracks and plays or shuffles them | 5 |
| Explore catalogue pages | Listener opens track, artist, album and licence pages to learn and play | 10 |
| Search the catalogue | Listener searches tracks, artists and playlists and filters results by type | 4 |
| Control what plays next | Listener uses Now playing, the queue and keyboard shortcuts to steer playback | 8 |
| Create an account and sign in | Visitor signs up, confirms their email, signs in and signs out | 15 |
| Reset a forgotten password | Listener requests a reset link by email and chooses a new password | 4 |
| Like tracks and follow artists | Signed-in listener likes tracks, follows artists and finds them in Library | 6 |
| Build playlists | Listener creates, renames, fills, edits and deletes their own playlists | 13 |
| Share music | Listener shares a link; anyone opens it and listens without an account | 8 |
| Get a personal Home | Listener sees a greeting, featured mix, recent plays, new releases and artists | 5 |
| Manage settings | Listener edits profile, playback, theme and email preferences, applied on every device | 12 |
| Stay informed | Listener reads notifications about releases, shares and milestones and clears unread ones | 6 |
| Report a track | Listener reports a copyright, licence or safety problem without revealing their identity | 3 |
| Get clear feedback | Listener sees toasts, banners, accessible dialogs and error pages, all keyboard operable | 15 |
| Listen offline | Listener opens cached pages and plays saved tracks without a connection | 5 |
| **Total** | | **135** |
